#### 告警联动控制功能说明

##### 一、功能概述

告警联动控制功能用于在系统检测到特定告警条件时，自动触发联动控制动作，实现设备能力调用，如声光告警器启动、视频联动、继电器控制等。

该功能以结构物（Structure）为单位配置联动规则，当结构物产生特定类型的告警数据时，根据预设规则自动执行相应的联动动作。

##### 二、数据结构说明

所有联动规则配置存储于数据库表 `t_alarm_link` 中，字段包含规则名称、触发条件（triggers）、联动动作（actions）等，存储格式为 JSON。

###### 示例数据：

```json
{
  "name": "多结构物声光告警",
  "actions": [
    {
      "type": "iot-cap",
      "parameters": {
        "body": {
          "param": "1",
          "thingId": "123456",
          "timeout": 10000,
          "deviceId": "12345678980",
          "dimCapId": "223344"
        }
      }
    }
  ],
  "triggers": [
    {
      "status": [1, 2],
      "structure": 1,
      "categories": [2]
    }
  ]
}
```

###### 字段说明：

- **name**：规则名称
- **triggers**：触发条件数组
  - **structure**：结构物ID
  - **categories**：告警类型（1设备类告警 2数据类告警）(不填默认所有类型)
  - **status**：告警状态（1告警待确认 2告警确认）(不填默认所有状态)
- **actions**：动作数组
  - **type**：动作类型，如 `iot-cap` 表示调用物联网能力
  - **parameters**：动作参数，通常包含设备ID、能力ID、超时等

##### 三、功能逻辑

1. **触发判断**：
   - 当系统接收到告警数据时，Alarm-Flink 进程会比对该数据所属结构物ID、告警类型、状态，是否满足 `t_alarm_link` 中的某条规则的触发条件。
2. **动作执行**：
   - 若满足某条规则的触发条件，Alarm-Flink 将解析对应的动作数组，依次执行每个动作。
   - 当前支持的动作类型主要为 `iot-cap`，即通过调用设备能力接口（如开启声光告警）。
3. **调用示例**：
   - 当结构物ID为`1`的结构物产生数据类告警时，将自动调用 `thingId=123456` 的设备能力 `dimCapId=223344`。

##### 四、处理模块

该逻辑由 **Alarm-Flink** 进程负责，代码路径：

- **代码位置**：
   `FS-Anxinyun\trunk\codes\services\alarm`
- **构建地址（Jenkins）**：
   https://jenkins.ngaiot.com/job/alarm-flink/

Alarm-Flink 模块会定时拉取或监听告警数据流，并实时处理是否满足联动规则，并执行对应控制动作。

##### 五、扩展方向

- 支持多动作串行/并行执行
- 支持动作失败重试机制
- 支持规则配置前端化、热加载
- 支持更多动作类型（如发送MQTT消息、调用`WebHook`等）
