# 光电挠度仪数据格式说明

通过MQTT发送，数据格式为JSON，其格式如下：

#### JSON 格式
```json
{
  "command": "result",
  "type": "reply",
  "values": {
    "sensors": [
      {
        "arg": "参数值",
        "des": "描述信息",
        "pos": "传感器位置",
        "tar": "目标值",
        "xReal": 浮点数值1,
        "yReal": 浮点数值2,
        "timestamp": "时间戳"
      }
    ],
    "timestamp": "时间戳"
  }
}
```

#### 字段说明

- **`command`**：命令类型，固定值为 `"result"`。
- **`type`**：数据类型，固定值为 `"reply"`。
- **`values`**：
  - **`sensors`**：传感器数组，包含多个传感器的测量值。
    - **`arg`**：传感器参数值。
    - **`des`**：传感器描述信息。
    - **`pos`**：传感器位置标识。
    - **`tar`**：目标值。
    - **`xReal`**：传感器测量的X轴浮点数值。
    - **`yReal`**：传感器测量的Y轴浮点数值。
    - **`timestamp`**：传感器数据的时间戳，格式为 `"2006-01-02 15:04:05.999"`。
  - **`timestamp`**：传感器数据的整体时间戳，格式同上。
