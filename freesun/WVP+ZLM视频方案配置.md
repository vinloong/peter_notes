## WVP+ZLM视频方案配置



| 配置项         | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| `id`           | 媒体服务节点唯一标识（推荐使用 SIP ID 格式，必须唯一）。     |
| `ip`           | 媒体服务对外访问的 IP 地址，WVP 会通过此地址访问 ZLMediaKit 的 API 接口。 |
| `hookIp`       | ZLMediaKit 触发事件回调时使用的地址（一般与 `ip` 一致）。    |
| `sdpIp`        | 生成 SDP 时使用的 IP，决定了媒体流向哪里发。**必须是外网可以访问的地址**。 |
| `streamIp`     | **生成流地址用的 IP**。用于组装 RTSP/RTMP 播放地址。         |
| `port`         | ZLMediaKit 的 HTTP API 服务端口，默认是 `826`。              |
| `secret`       | API 鉴权密钥，需要和 ZLMediaKit 配置中的 `api.secret` 保持一致。 |
| `rtspPort`     | ZLMediaKit 提供的 RTSP 服务端口，默认 `554`。                |
| `rtmpPort`     | ZLMediaKit 提供的 RTMP 服务端口，默认 `1935`。               |
| `rtpProxyPort` | RTP 代理端口范围起始值，ZLM 会自动分配使用。                 |
| `autoConfig`   | 是否自动配置媒体服务参数到 ZLMediaKit（如果设为 `true`，WVP 启动时会自动调用 ZLM API 进行设置）。 |



## 📌 收流端口的用途

**需要将UDP端口暴露到公网**

| 作用                     | 描述                                                         |
| ------------------------ | ------------------------------------------------------------ |
| 接收设备推送的 RTP 流    | 国标设备通过 SIP 协议注册到 WVP，之后 WVP 控制设备向某个收流端口发送视频流。 |
| 用于媒体服务端口动态分配 | 每一路流使用一个独立的端口来接收 RTP，避免端口冲突。         |
| 由 ZLM 启动时自动监听    | 收到流后转封装为 RTMP/RTSP/HLS 等流格式供客户端拉流。        |
