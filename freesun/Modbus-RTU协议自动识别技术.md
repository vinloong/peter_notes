# Modbus-RTU协议自动识别技术

## 背景
本技术实现了对任意数据流的Modbus-RTU协议自动识别和解析功能。通过分析输入的字节流和对应的数据结果，自动识别协议格式、数据类型和字节序，并建立数据映射关系。

## 技术原理

Modbus-RTU协议格式如下：

```
[设备地址][功能码][数据长度][数据内容][CRC校验]
    1字节    1字节     1字节      N字节     2字节
```

识别流程

1. **协议验证**：验证CRC校验码确认是否为有效Modbus-RTU报文
2. **数据提取**：提取数据部分字节
3. **格式解析**：尝试不同数据类型和字节序进行解析
4. **匹配度计算**：将解析结果与期望数据进行匹配度分析



### 应用场景

- 工业自动化设备调试
- 通信协议分析
- 设备对接测试
- 数据采集系统配置
- 协议逆向工程



---

## 输入说明

1. **Modbus码流**：类型为字节数组(`byte_array`)，表示传入的Modbus-RTU协议数据帧。
2. **数据映射(JSON格式)**：类型为字符串(`result_json`)，表示目标数据字段及其值的映射关系，例如：
   ```json
   {"pressure": 100, "temperature": 25}
   ```

---

## 输出说明
程序输出如下信息：
1. 是否符合Modbus-RTU协议：
   - 校验报文结构和CRC校验。
   - 显示数据部分字节内容。
2. 数据字段匹配：
   - 针对数据部分的每个数据域字节，分析其转换后的数值与映射字段值的匹配度。
   - 显示匹配度及详细信息。

---

## 示例输出解析
**用例1**

```plaintext
用例1
输入：
某压强传感器
报文：\x08\x42\xC8\x00\x00\x41\xC8\x00\x00\x7D\xEA
数据：{"pressure":100,"temperature":25}

输出：
报文符合Modbus-RTU规定, CRC校验低位在前
数据部分字节: 42C8000041C80000
数据字典长度 = 2
数据域[0-3]字节[42C80000]大端字节序转换浮点数值结果与[pressure]较匹配(匹配度 1.00)
数据域[4-7]字节[41C80000]大端字节序转换浮点数值结果与[temperature]较匹配(匹配度 1.00)
```

在此输出中：
1. 报文符合Modbus-RTU协议，且CRC校验通过。
2. 数据部分字节为`42C8000041C80000`，表示两段数据域。
3. 第一个数据域`42C80000`解析为浮点数100，与目标字段`pressure`完全匹配，匹配度为1.00。
4. 第二个数据域`41C80000`解析为浮点数25，与目标字段`temperature`完全匹配，匹配度为1.00。

**用例2**
```plaintext
用例2
输入：
TL740D 陀螺转角仪
报文：\x01\x03\x0C\xF3\x49\x02\x00\x1D\x4E\x00\x00\x02\x4F\x00\x00\x50\x1C
数据：{"x":0.03,"y":-0.003,"z":22.26}

输出：
报文符合Modbus-RTU规定, CRC校验低位在前
数据部分字节: F34902001D4E0000024F0000
数据字典长度 = 3
数据域[0-3]字节[F3490200]大端字节序转换浮点数值结果与[x]较匹配(匹配度 0.30)
数据域[0-3]字节[F3490200]大端字节序转换浮点数值结果与[y]较匹配(匹配度 0.30)
数据域[0-3]字节[F3490200]大端字节序转换浮点数值结果与[z]较匹配(匹配度 0.30)
```

在此输出中：
1. 报文符合Modbus-RTU协议，且CRC校验通过。
2. 数据部分字节为`F34902001D4E0000024F0000`，表示三段数据域。
3. 第一个数据域`F3490200`解析为浮点数，与目标字段`x`、`y`、`z`的匹配度均为**0.30**。(此协议数据部分转换复杂度较高，没有准确匹配数据解析方法)
