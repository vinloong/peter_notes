# 光电挠度仪数据格式说明

## 1. 数据类型概述
本系统通过MQTT协议向上层系统发送不同类型的数据，主要包括以下几类：
1. **传感器数据（`SensorData`）**：包含设备采集的传感器测量值。
2. **图片数据（`ImageData`）**：设备采集的图像数据。
3. **透传数据（`PassThroughData`）**：设备与系统之间的原始通信数据。

## 2. 数据结构定义

### 2.1 传感器数据（`SensorData`）
传感器数据是系统的主要输出之一，其格式如下：

#### JSON 格式
```json
{
  "command": "result",
  "type": "reply",
  "values": {
    "sensors": [
      {
        "arg": "参数值",
        "des": "描述信息",
        "pos": "传感器位置",
        "tar": "目标值",
        "xReal": 浮点数值1,
        "yReal": 浮点数值2,
        "timestamp": "时间戳"
      }
    ],
    "timestamp": "时间戳"
  }
}
```

#### 字段说明
- **`command`**：命令类型，固定值为 `"result"`。
- **`type`**：数据类型，固定值为 `"reply"`。
- **`values`**：
  - **`sensors`**：传感器数组，包含多个传感器的测量值。
    - **`arg`**：传感器参数值。
    - **`des`**：传感器描述信息。
    - **`pos`**：传感器位置标识。
    - **`tar`**：目标值。
    - **`xReal`**：传感器测量的X轴浮点数值。
    - **`yReal`**：传感器测量的Y轴浮点数值。
    - **`timestamp`**：传感器数据的时间戳，格式为 `"2006-01-02 15:04:05.999"`。
  - **`timestamp`**：传感器数据的整体时间戳，格式同上。

### 2.2 图片数据（`ImageData`）
图片数据是设备采集的图像信息，其格式如下：

#### JSON 格式
```json
{
  "command": "image",
  "type": "reply",
  "values": {
    "image": "base64编码的图像数据"
  }
}
```

#### 字段说明
- **`command`**：命令类型，固定值为 `"image"`。
- **`type`**：数据类型，固定值为 `"reply"`。
- **`values`**：
  - **`image`**：图像数据，以Base64编码的字符串形式发送。

### 2.3 透传数据（`PassThroughData`）
透传数据是设备与系统之间的原始通信数据，其格式如下：

#### JSON 格式
```json
{
  "command": "透传命令",
  "type": "透传类型",
  "values": "透传数据内容"
}
```

#### 字段说明
- **`command`**：透传命令内容。
- **`type`**：透传数据类型，可能是 `"pass-up"` 或 `"pass-down"`。
- **`values`**：透传数据的具体内容，通常为设备的原始通信数据。

## 3. 数据发布逻辑
1. **传感器数据发布**
   - 每次设备采集到传感器数据后，系统会根据配置的限流策略（如每秒1条或自定义速率）将数据发布到MQTT主题。
   - 数据发布到的主题格式为：`<MqttTopicBase>`。
   - 数据的时间戳会根据本地时区（北京时区）进行格式化。

2. **图片数据发布**
   - 图片数据默认不发布。
   
   - 需要请求转发程序HTTP的设置。

     ```sh
     POST :4101/setImageUpEnable?enable=1
     ```
   
   - 数据发布到的主题格式为：`<MqttTopicBase>/image`。
   
3. **透传数据发布**
   - 当系统接收到设备的透传数据时，会将其发布到MQTT主题。
   - 数据发布到的主题格式为：`<RawMqttTopicBase>/pass-up`。

## 4. 配置说明
- **传感器数据主题**：`<MqttTopicBase>`
- **图片数据主题**：`<MqttTopicBase>/image`
- **透传数据主题**：`<RawMqttTopicBase>/pass-up`

其中，`<MqttTopicBase>` 和 `<RawMqttTopicBase>` 是在设备配置中定义的基础主题路径。

配置说明

```yml
devices:
  - ip: "设备IP地址:端口"
    name: "设备名称"
    mqtt_broker: "MQTT代理服务器地址"
    mqtt_topic_base: "MqttTopicBase MQTT基础主题"
    csv_path: "CSV文件存储路径"
    limit: "数据限流配置"
```

示例

```yml
devices:
  - ip: "127.0.0.1:2231"
    name: "local"
    mqtt_broker: "tcp://xxx:1883"
    mqtt_topic_base: "/fs-flexometer/local"
    csv_path: "./127.0.0.1"
    limit: "1,1"

```
