### 云端滑坡识别告警数据格式说明

#### 1. 系统简介

本系统实现了基于AI算法的滑坡灾害识别，通过接入海康摄像头，利用部署在服务器上的海康ISC平台进行视频流管理，配合云端抓图与图像解算处理，实现滑坡灾害自动识别和告警推送。

识别结果将通过 MQTT 协议发布至指定平台，用于后续平台显示或应急响应联动。

------

#### 2. MQTT 接入信息

- **MQTT 服务器地址**：`mqtt.datahub.anxinyun.cn`

- **协议端口**：默认 `1883`（无加密）

- **`QoS`**: 1或2

- **发布主题格式（Topic）**：

  ```php+HTML
  landslide/alert/<摄像头序列号>
  ```

  示例：

  ```php+HTML
  landslide/alert/20250412CCCHFY8123364
  ```

------

#### 3. 报警消息内容格式

消息采用 JSON 格式，字段说明如下：

##### JSON 数据结构

```json
{
  "deviceId": "20250412CCCHFY8123364",
  "alarmTime": 1716189023,
  "alarmType": "landslide",
  "alarmMsg": "检测到疑似滑坡区域",
  "photoData": "<base64编码图片数据>"
}
```

##### 字段说明

| 字段名      | 类型   | 是否必填 | 含义                       | 示例值                     |
| ----------- | ------ | -------- | -------------------------- | -------------------------- |
| `deviceId`  | string | 是       | 摄像头设备序列号或ID       | `20250412CCCHFY8123364`    |
| `alarmTime` | long   | 是       | 报警时间（Unix时间戳，秒） | `1716189023`               |
| `alarmType` | string | 否       | 报警类型（如滑坡/崩塌）    | `landslide`                |
| `alarmMsg`  | string | 是       | 报警描述信息               | `检测到疑似滑坡区域`       |
| `photoData` | string | 是       | 报警截图的Base64编码       | `iVBORw0KGgoAAAANSUhEU...` |
